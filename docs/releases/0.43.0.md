# Culto Studio 0.43.0

- Aviso de nuevas versiones al abrir, sin interrumpir la proyección.
- Opción Buscar actualizaciones en Configuración.
- Descarga con progreso, cancelación y verificación antes de instalar.
- Instalador de Windows con accesos directos y desinstalador; conserva cultos y ajustes.
- Plugin nativo para Elgato Stream Deck y mejoras de reconexión del mando móvil.

Windows x64. El instalador incluye el programa y sus componentes; el contenido multimedia completo se distribuye aparte. Para esta primera versión con actualizaciones, instala el EXE manualmente una vez. Las próximas versiones publicadas se anunciarán dentro del programa.
