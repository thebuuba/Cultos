# Escenas editables

Objetivo: administrar las escenas como botones de Deckboard, conservando las acciones existentes.

- Guardar una lista ordenada con identificador estable, nombre, acción, color, imagen del botón y contenido opcional. Migrar las seis escenas actuales al abrir un espacio existente.
- Añadir un editor con vista previa, selección de contenido y una imagen independiente. Añadir, editar, duplicar, ordenar y eliminar desde el panel Escenas. Eliminar el acceso nunca elimina el archivo ni interrumpe la proyección.
- Publicar la misma lista, aspecto y estado al mando; validar las acciones contra la lista vigente.
- Verificar persistencia, aislamiento del contenido entre escenas, eliminación, orden, imagen personalizada y compatibilidad del mando. Compilar y actualizar la instalación local si está cerrada.

Referencias: https://www.deckboard.app/ y https://github.com/rivafarabi/deckboard (consultadas el 14 de noviembre de 2026).
